Proyecto integrador 2

Este proyecto propone el desarrollo de un sistema de autoservicio para el abastecimiento automatizado de combustible, integrando mecanismos de pago electrónico, control centralizado en la nube y protocolos de seguridad activa ante riesgos operacionales. El diseño de la solución está orientado a maximizar la eficiencia del proceso de carga, optimizar el uso de recursos físicos y humanos, y garantizar la continuidad segura de las operaciones. A través de una arquitectura IoT que conecta el hardware de campo con plataformas en la nube, el sistema mejora la experiencia del usuario y ofrece a las empresas un control auditable, automatizado y en tiempo real sobre el suministro y las ventas.

Instrumentación y medidas

Desarrollo de un sistema electrónico enfocado en la medición y corrección del factor de potencia en una red eléctrica de baja tensión utilizando un ESP32. El proyecto comprende la simulación analítica en LTspice y el diseño de circuitos de acondicionamiento de señal con amplificadores operacionales, optimizando la etapa de conversión analógico-digital (ADC) para garantizar lecturas óptimas. El núcleo del trabajo aplica técnicas de instrumentación destinadas a cuantificar los errores en las medidas y asegurar la precisión necesaria en el cálculo de los valores eficaces (RMS) de tensión, corriente y frecuencia. Finalmente, el sistema visualiza las variables en una interfaz HMI (FUXA) y ejecuta una compensación reactiva discreta mediante el acoplamiento controlado de condensadores.

Diseño de sistemas de control

Diseño e implementación en tiempo real de sistemas de control sobre una planta física de par motor-generador DC de diseño propio. El proyecto integra una fase teórica de modelado matricial y simulación en Xcos (observadores de estado y sistemas seguidores), consolidándose en la aplicación práctica de un controlador PID y un sistema seguidor configurados para cumplir con especificaciones estrictas de tiempo de asentamiento, velocidad de respuesta y error nulo.
